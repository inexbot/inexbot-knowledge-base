# 纳博特机器人标定方法参考

## 工具手标定（5种方法）

| 标定方式 | 功能 | 适用场景 |
|---|---|---|
| **6点标定** | 校准工具手尺寸+姿态，C轴旋转精度较好 | 已做过激光标定+使用焊枪 |
| **7点标定** | 校准工具手尺寸+姿态，A/B轴精度较好 | 6点标定后A/B轴误差大 |
| **12点标定** | 校准2/3/4/5轴零点+工具手尺寸（无旋转参数） | 未做过激光标定+使用焊枪 |
| **15点标定** | 校准2/3/4/5轴零点+工具手尺寸+姿态（无旋转参数） | 需要同时校准零点和姿态 |
| **20点标定** | 校准2/3/4/5轴零点+工具手尺寸 | 零点丢失；标定后再用实际工具做6点 |

### 选择建议
- **码垛夹抓**：优先直接填工具尺寸（X/Y/Z轴偏移），不需标定
- **零点丢失**：20点标定校零点 → 再6点标定工具手
- **6点标定后A/B轴旋转误差大**：更换7点标定

### 验证精度
示教模式下，工具手末梢对准标定锥 → 切换直角坐标系 → 点动A/B/C轴 → 观察尖端偏移mm数

## 零点标定
- **对位孔标定**：简单，适合快速恢复
- **20点标定**：精度更高，适合已丢失零点的机器人
