## C1102

来源：`md/zh-产品资料-控制系统-工业机器人控制器C1102.md`「产品参数」表（2026-10-24 逐行核对）

| 项目 | 规格 |
|------|------|
| CPU | Intel Celeron J1900 2.0GHz |
| 内存 | 4G |
| 电源 | 24V（±10%） |
| 操作系统 | Linux RT |
| 网口 | 1×EtherCAT，1×Ethernet（共 2 个网口） |
| USB | 1×USB 3.0，3×USB 2.0 |
| 串口 | 1×RS232，1×RS485 |
| 示教器 | （选配）T30，8 寸 TFT 全触屏，Linux+QT |
| 控制轴数 | 64 轴同步插补运动 / 串联 6 轴机器人 + 地轨 + 2 轴变位机 × 2 |
| 通讯协议 | EtherCAT、Profinet、Ethernet/IP、OPC-UA、FinsTCP、TCP/IP、ModbusTCP、ModbusRTU |
| 操作模式 | 示教模式、再现模式、远程模式 |
| 编程方式 | 示教编程、离线编程、拖动示教 |
| 运动功能 | 点到点、直线、圆弧、样条曲线、直线横摆、FLYBY |
| 位置控制方式 | 点到点控制、连续轨迹控制 |
| 坐标系统 | 关节坐标系、机器人坐标系、工具坐标系、用户坐标系 |
| 结构算法 | 6 轴串联机器人等 20 余种构型 |

> ⚠️ **C1102 的 DI/DO 数量与 CAN 路数在官方产品资料中未列出**（该表只有网口/USB/串口三类接口行）。
> 早前版本本文件曾写「16 路 DI + 16 路 DO / 1 路 CAN」——那是 **C1201** 的规格（见下节），**C1102 无此数据**。
> 需要 C1102 的板载 DI/DO 数量与 CAN 口数量时，须向纳博特索取 C1102 硬件规格书/接线图，**不要**把 C1201 的数值套用。
> 另注意：C1102 通讯协议列表里**没有 CANopen**（该协议是控制器主站侧的总线类型之一，勿与板载 CAN 串行口混淆）。

## C1200

⚠️ **本节数据未经官方产品资料核对，勿直接引用**（2026-10-24 复核时发现 KB `md/` 目录下
**没有** `产品资料-控制系统-工业机器人控制器C1200.md` 独立文档；C1200 只在《操作手册-24.03版本-
系统功能调试手册》的程序名对照表里以 `C1200_X64_Linux-RT_Robot-controller` 出现过）。

早前记录的「3×Ethernet / 16DI+16DO / 5s 断电保护」**疑似是 C1201 规格的串位**：
C1201 官方产品资料明确写的是 3×Ethernet、16×隔离 DI + 16×隔离 DO、**10s** 断电保护（不是 5s）。
C1200 与 C1201 是两个独立 SKU（程序名 C1200_X64 vs C1201_X64），**不可互相套用**。

C1200 的真实接口规格：向纳博特索取 C1200 产品资料或硬件规格书后再补。

## C1103（C1102 的升级替代品）

来源：`md/zh-产品资料-控制系统-工业机器人控制器C1103.md`（2026-10-24 核对）

| 项目 | 规格 |
|------|------|
| CPU | Intel Celeron J1900, 2.0GHz, 4核4线程, 2MB L2, TDP 10W（**与 C1102 同平台**） |
| 内存 | DDR3L 4GB 标配，SO-DIMM 插槽最高 8GB |
| 存储 | eMMC 64GB 板载 + M.2 2242 SATA 扩展（64G~1TB）/ 4G/5G 模组 |
| 以太网 | LAN1: EtherCAT OUT 独立 RJ45；LAN2: Intel i210-AT 千兆；LAN3/4: RTL8111H 千兆 |
| 串口 | 2×RS485 (COM1/2) + 2×RS232 (COM3/4)，最大 115.2kbit/s（**是 C1102 的 2 倍**） |
| E-BUS | 高速扩展总线，可扩 AL 系列 IO 模块 13 种型号（数字量/模拟量/温度/编码器输入） |
| 显示 | HDMI 1920×1080@60Hz（**优于 C1102 的 VGA 模拟接口**） |
| USB | 3×USB 2.0 |
| 电源 | DC 24V (-15%/+20%)，过流/过压/防反接，内置 UPS 超级电容（满载 ≥5s） |
| 机械 | 103×97×74.5mm，1.5kg，DIN-Rail IEC 60715（**C1102 是 230×120×50mm，体积约 0.74L vs 1.38L**） |
| 环境 | 工作 -20℃~60℃，存储 -40℃~80℃，95%湿度，3Grms 振动，30G 冲击，CE/FCC Class A |
| 操作系统 | **Windows 7/10、Ubuntu、Debian** |
| 运动能力 | 最高 64 轴同步运动，可独立控制 4 台机器人并外接地轨/变位机等外部轴 |

> ⚠️ **C1103 的「操作系统」不是 RT-Linux**——产品资料列的是 Windows 7/10、Ubuntu、Debian。
> 但其**软件/固件与 C1102 生态完全兼容**（同 J1900 平台，迁移成本极低），
> 现场做机器人控制时跑的是纳博特内置控制系统。不要把它当成普通 PC 盒子对待。

## 通用通讯协议

所有型号均支持：EtherCAT、ModbusTCP/ModbusRTU、TCP/IP、FinsTCP、OPC-UA、Ethernet/IP（部分型号）
