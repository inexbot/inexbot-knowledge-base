## 1. ⚠️ 两册参数体系完全不同，不能混用

这是本主题最大的坑。2.0 和 3.0 的参数**不是同名同义**，回答时必须分节写清楚哪条属于哪一册。

| | 2.0 手册 | 3.0 手册 |
|---|---|---|
| 参数入口 | 顶部菜单【参数】 | 程序界面底侧状况栏【设置】；【冲压参数】面板需**长按右上角时间下面位置 2 秒**才显示（再长按 2 秒隐藏） |
| 组织方式 | 按「板块」分 9 个：通讯／前站／本站／工艺／干涉区／冲压IO／治具／可变气缸／送料机 | 按「工位角色」分：上料机／搬运／下料机／单机 的取料参数+放料参数；另有 冲压参数（功能启用／IO参数／进阶参数／速度参数／产线换向／单机参数／电磁铁参数）、气缸治具、码垛参数 |
| 治具 | 治具设置：前置延时、触发式/接近式传感器、通断延迟报警、辅助点 | 气缸/治具：治具类型（吸盘/电磁铁/气缸/禁用）、吸气测试、吹气测试、通断延时报警、真空检测开关 |
| 冲床 IO | 2.6 冲压IO：10 个输入 + 9 个输出（信号名是语义名，不带 X/Y 端口号） | 附表 IO 定义：X02/X03/X05/X06/X11/X12/X13/X14/X16、Y05/Y06/Y11/Y12/Y14/Y15（**带固定端口号**） |
| 码垛 | 无专章（程序创建里提到码垛开关） | 码垛参数章：卸垛参数 + 码垛参数 |
| 权限 | 用户权限（管理员可所有操作） | 操作员／技术员／管理员三级；强制冲压按钮仅管理员 |

## 2. 版本归属：冲压工艺手册**不按固件版本分册**

doc.inexbot.com 大部分操作手册是按 `22.07版本/ 24.03版本/ 25.01版本/` 目录组织的，但**冲压工艺两册例外** —— 它们挂在 `操作手册/专机手册/冲压专机/` 下，不含版本号。

⚠️ 因此 **SKILL.md §「长手册型主题」第 4 条「扫 index 标题就知道某手册只存在于哪个固件版本」对本主题不成立** —— title 不带版本信息，扫不出来。

**判定的 ground truth：解析 raw HTML 侧边栏**，看某个页面出现在哪个版本分节下。

```python
import re
from pathlib import Path
p = Path.home()/".hermes/kb/inexbot/raw/zh-操作手册-专机手册-冲压专机-冲压工艺3.0手册.html"
t = p.read_text(encoding="utf-8", errors="ignore")
heads = [(m.start(), m.group(0)) for m in re.finditer(r">(2[0-9]\.0[0-9]版本)<", t)]
for m in re.finditer(r'href="(/zh/[^"]*%E5%86%B2%E5%8E%8B[^"]*)"', t):
    ver = "?"
    for hpos, htxt in heads:
        if hpos < m.start(): ver = htxt
    print(ver, "->", m.group(1))
```

实测结论（2026-11-07）：22.07 分节 24 条链接里**不含**冲压工艺两册；24.03 分节 30 条不含；25.01 分节 58 条里**含**冲压工艺 2.0 / 3.0 两册（链接出现在 25.01 分节内的「专机手册」分组）。

⇒ **准确表述是**：冲压工艺手册**归属于 25.01 版本目录**，22.07 / 24.03 的操作手册目录下没有冲压工艺专机手册。
（`index.json` 里 URL path 是 `.../专机手册/冲压专机/冲压工艺2.0手册`，不带版本号 —— 所以 path 和 title 都证明不了版本。）

⚠️ **别对固件版本差异做类推**：24.03 固件上跑冲压工艺时参数名是否与 25.01 一致，KB 无据可查 → 回答时明写「无法确认，建议索取对应版本出厂参数配置单」。

## 4. 2.0 手册参数板块速查

入口：顶部菜单【参数】。

1. **通讯参数**：联机模式四选一 —— 单机（独立运行，功能尚未完善）／上料（起始站，不跟前站通讯，只跟后站交互）／搬运（中间站）／下料（末端站，有自检测）。网络参数：本站 IP（自动读取）、后站 IP、通讯状态、当前机器人数目（总台数/当前台数）。前后站不满足设定即报「连线异常」。
2. **前站参数**：信号交互 —— 输出取料完成（输入信号）、输出放料完成（输入信号）、前站允许取料/放料（前站输出）、取料迟滞信号、放料迟滞信号（ms，到达待机点后的延迟）。前站冲床：打开「前站有冲床」→ 最大冲床数 + 冲床编号（一号对应一组冲床参数）。
3. **冲床详细参数**（2.0 最关键的一组）：允许控制冲压（**打开后才能设下方项**）、上死点（接 IO 输入；未接时默认恒在上死点）、冲压时长（给冲压使能到上死点消失再亮的时间，ms）、冲压动作时长（上死点消失→重新亮起，ms）、强制冲压（紧急操作，弹窗）、冲床类型（齿轮/气动/油压/自定义）、启动时上死点检测、下死点检测、延迟复位时间（ms）、冲压超时设置（上死点→下死点→上死点上限，ms）、冲压模内检测（料片位置信号，一般光栅或感应器，防压坏模具）、反应超时设置（发冲压信号→上死点消失，超时报警并发急停冲床）、冲压成功确认时间（上死点复位时间大于该值才记一次冲压，防信号闪烁误判）。
4. **本站参数**：本站类型四选一 —— 放料台（仅末台机放料）／冲床（首台+中间机接冲床）／翻转台（首台+中间机接翻转台）／空中接力（无翻转台时用外部轴或变位机翻转）。+ 取料/放料迟滞信号（ms）。
5. **工艺参数**：工艺号（保存不同用户/工艺的参数）、联机选中（把参数下发其他站）、复制工艺号、默认程序。运动控制：首模速度比（首模按全局速度的百分比，最大 100%）、模内逃跑使能、模内逃跑运动方式（关节/直角）、模内逃跑速度比（默认 99%）。
   - **模内逃跑两阶段**：去程（待机点→取/放料点）沿原轨迹**反向**退回待机点；回程（取/放料点→待机点）走**最短路径**直接返回。
6. **干涉区**：坐标系参照机器人原点 X、Y 方向，**只需标记干涉区原点坐标**即可完成标定。选项：前站冲床／本站冲床／机器人。用途是切换前后站位置，按实际产线方向调。
7. **冲压 IO**：输入 10 项 —— 冲床急停、冲床上死点（前站/本站）、单次冲压检测、冲床下死点、冲床模内检测、治具检验、前站允许取料、本站允许放料、投料信号、安全门信号。输出 9 项 —— 冲压信号、急停冲床、治具状态、前站干涉区输出、本站干涉区输出、翻转台取料成功、翻转台放料成功、治具辅助选择一/二、请求投料。**安全门信号触发后整条产线暂停。**
8. **治具设置**：取料前置延时／放料前置延时（ms，到位后延迟）、传感器类型（触发式=执行抓取后才有信号／接近式=到位即有信号）、治具一/二的通断延迟报警、辅助选择一/二辅助点持续（关闭治具信号后立刻输出，一般用于电磁阀消磁）。
   - **通断延迟报警时间语义**：设 0 → 到达待机点判断，满足则继续、不满足则报警；设长了 → 到达前满足直接继续，到达后未满足则等到时间结束，中途满足可继续，时间结束仍未满足则报警。
9. **可变气缸**：冲压内置**软 PLC** 功能，特定条件下打开某 IO 端口、特定条件下关闭。配置顺序：触发条件 → 触发延时（秒）→ 复位方式 → 气缸号（1–10）→ IO 端口 → 有效值 → 打开使能。
10. **送料机**：信号类型 —— 上升沿（给一次只取一次，必须断开再给）／常通通常（有信号就来取）／不检测。选项：投料机将料送到冲床、启用呼叫投料、呼叫投料超时设置、呼叫投料延时设置。

**2.0 程序创建**：新建程序（程序名以字母或汉字开头、类型=模板/指令、外部轴开关、码垛开关）；模板程序编辑用「标记点位 + 轨迹1-10 + 运动到点 + 治具1/治具2动作 + 保存」；模板→指令可转，反向不可转（不可逆）。
- **自定义编程必须包含 4 条待机点指令**（前往/回到前站待机点、前往/回到本站待机点），且每条待机点后必须紧跟对应的检测处理指令（取料前/后、放料前/后）。
- 外部轴打开后，程序里所有点位变成 **E 点**而不是 P 点。

**2.0 运行界面**：只有「启动、暂停、停止、回待机点后暂停、清料流程」在运行状态下点击生效，其余按键不生效。冲压使能打开后若没设置冲压输出信号则无法运行。无料运行会屏蔽治具开关并自动打开屏蔽检测（且无法关闭）。联机状态复位必须在所有机器人停止时进行。虚拟上死点开关用于冲床关闭时调试轨迹。

## 5. 3.0 手册参数速查

### 5.1 工艺参数（按工位角色）

**上料机 · 取料参数（上料台）**
- 是否启动检测：打开按信号类型检测，关闭不检测。
- 信号类型（X13）：常亮 = X13 置 1；上升沿 = X13 由 0 置 1；常灭 = X13 置 0；下降沿 = X13 由 1 置 0。
- 是否启动卸垛：打开才调用卸垛功能。

**放料参数 —— 冲床**（各模式通用）
- 上死点（绿/红指示）、冲压时间（记录一次冲压耗时）、冲压（强制冲压按钮，**仅管理员模式**）、是否启动冲压、冲床输出时间（例 800 = 冲床启动信号维持 800 ms 后关闭）、**冲压最长周期 / 最短周期**（超出范围判为冲压异常）。

**放料参数 —— 中转台**：选中转台后机器人**不启动冲床、不判断上死点**，只判断允许放料信号。「屏蔽允许取料信号」打开后上料机放料时不再判断允许放料信号。

**搬运**：取料参数-冲床（上死点指示 + 允许取料信号 X13 置 1 绿灯 / 置 0 红灯）；取料参数-中转台（不显示上死点和允许取料信号灯，只判断允许取料信号）；放料参数同放料工位规则。

**下料机**：取料参数同搬运；放料参数 = 是否启动检测（X14，信号类型四种同上）+ 是否启动码垛。
- **硬性约束**：上料机放料工位选冲床时，下一台机器人取料工位的本站类型必须一致（冲床↔冲床、中转台↔中转台）。

**单机**：本站类型只有「供料」；是否启动检测 + 信号类型（X13）；放料参数只有冲床；「屏蔽允许放料」打开则不检测 X14。

### 5.2 气缸 / 治具
- 治具类型：1 吸盘、2 电磁铁、3 气缸、4 禁用。
- 吸盘判断逻辑：取料点打开主副吸料开关并判断是否构成真空，放料点关闭并判断是否破空。**电磁铁的差别是在放料点上方-回判断是否破空。**
- 吸气测试（主吸料 Y05／副吸料 Y06）、吹气测试（主吹气 Y07／副吹气 Y08）、吹气时间（ms）、通断延时报警（ms，吸盘吸料检测时间）、辅助点-吹洗料台（不启用/启用）。
- **真空检测开关的两种行为**：
  - 关闭：按治具 1、2 的通断延时报警值**取较大者**，在取料点和放料点停留相应时间。
  - 打开：吸到料直接离开取料点、放完料直接离开放料点；取料点未吸到料 → 运行到取料待机点-回报「真空检测失败」；放料点失败 → 回放料待机点-回报「破空检测失败」。
- ⚠️ 3.0 手册明确写：**可变气缸 1 / 2 = 「暂未做功能」**（与 2.0 把它当软 PLC 可配置完全不同）。

### 5.3 冲压参数面板（隐藏入口）

**功能启用（13 项）**
- 生成模板覆盖同名文件（示教编程标定生成的文件可覆盖旧同名作业文件）。
- 强制冲压（打开后在冲压时间后显示按钮，防工人误操作）。
- 全程上电（按伺服键直接上电；**用于 T34、T41 无伺服使能键的示教器**）。
- 按轨迹进行复位（开启=按指令轨迹回取/放料待机点；关闭=ZXY 各轴依次复位。**开启用于六轴串联多关节机器人，关闭用于摆臂机器人**）。
- PLC 联机通信（允许取料/允许放料改由 **Modbus** 控制，IO 接线信号失效；用于 PLC 总控多台机器人信号交互）。
- 使用完整码垛（调用完整码垛工艺，参数更详细；用于多垛堆或垛堆复杂场景）。
- 码垛双垛堆（可调用完整码垛工艺 1 和工艺 2；关闭只能调用工艺 1）。
- 开机使用关节坐标系（断电重启/软重启默认关节坐标系，关闭则直角坐标系）。
- 取料冲床使用允许取料（上料机拿到允许取料信号就直接启动冲床；关闭则取料完成即启动冲床，**多用于卷料冲压**）。
- 治具上有料禁止启动（主吸盘真空置 1 时启动会警告手上有料）。
- 在取料点治具吸料（开启在取料点开吸盘吸气，关闭在取料上方点开；**用于气管过长、真空泵需启动时间的现场**）。
- 取料失败不关闭吸盘（报真空检测失败时不关闭主副吸料输出，用于判断机器人是否打开主治具真空）。
- 双吸盘取料（取料前检测两治具都有料或都无料，不一致则告警；用于单吸盘吸力不足或工件较重）。

**IO 参数**
- 真空检测信号（掉料/粘料时报错）、副治具真空检测信号。
- **Y13 真空泵保护**：开启后运行程序即打开 Y13；机器人停止且手上有料时 Y13 保持，**10 分钟后**关闭（用于关真空泵）。
- **X07 冲床安全信号**：启动冲床前判断 X07，置 1 才启动，否则不启动并报错（传感器常装在机器人一轴下）。
- **X07 机器人安全信号**：输出放料完成前判断 X07，无信号则不输出放料完成并报错（防大负载机器人提前启动冲床后机械臂相撞）。**与「X07 冲床安全信号」不能同时使用。**
- **X16 紧急急停**：开启则 X16 置 1 报紧急急停，关闭则不报（改为置 0 生效需改控制器配置文件）。
- **X17 启动 / X18 暂停**：X17 置 1 启动机器人；X18 置 1 则当前程序运行结束后在取料待机点暂停。

**进阶参数**
- 真空滤波参数（过滤主治具真空干扰，**最大 300**）。
- 冲压启动超时（发冲床启动信号后设定时间内上死点无变化则报错）。
- **点位最小间隔**（启动时对比取料待机点→取料上方点、放料待机点→放料上方点的 **Y 向距离**，小于设定值报错；填 0 不生效；防撞机）。
- 放料等待时间（ms，防粘料）、丢废料时间（ms，丢余料指令停留时间）、治具开关前延时（取/放料点停留后才开关治具，防末端抖动导致吸歪放歪）。

**速度参数**
- 首模运行速度（1–100）：机器人停止后再次启动，第一次运行按首模速度；**实际速度 = 全局速度百分比 × 首模速度百分比**。
- 复位速度（复位时按此速度；复位速度 20% = 全局速度 20%）。
- 低/中/高档位速度：点击全局速度后下拉栏对应的速度百分比。

**产线换向**
- 打开后不用换线即可换向，需提前接好两个冲床模式和两条冲床启动线，首尾两台机器人要改工艺参数里的工作模式。
- 换向输出 Y4：开启后 Y4 输出，供 PLC 读取反向状态。

**单机参数**
- 同取同放：开启后机器人在取料待机点**等待冲床冲压结束**（单机同时取料台料+冲床内已冲好的料，放未冲料到冲床+已冲好的料到料框）；关闭用于一次取放一张料。

**电磁铁参数**
- 叠料检测功能（取放料回上时检测叠料）、叠料检测高度（不能高于取放料点到取放料回上点的高度）、叠料检测处延时时间。

### 5.4 码垛参数
- **卸垛参数**：双垛堆卸料、X/Y/Z 方向个数（Z 填大于实际件数即可）、X/Y/Z 方向中心距（mm，对应工件宽/长/厚）、探料距离（垛堆厚度 mm）、探料回上速度（mm/s）、探料速度（1–100 mm/s）。
  - 计数逻辑：取料点构成真空且放料点构成破空 → 卸垛工件 +1。
  - 探料逻辑：取料点未构成真空 → 提示取料失败并开始探料，探到真空后继续往下放料。
  - 双垛堆开启后新增左料台/右料台取料点、左放料/右放料点，并新增 **X09、X10** 两个垛堆有料输入信号。
- **码垛参数**：首工件位置（右上/右下）、输出信号（码垛完一次输出 **Y17**，需配合传送带，码垛完成自动复位并重新开始）、信号输出时间（ms）、X/Y/Z 方向个数与中心距。
  - 码垛顺序：层内按 X、Y 正方向依次堆放，完成一层再上一层。
  - **生效范围：卸垛只在上料机模式生效，码垛只在下料机模式生效。**
  - 使用完整码垛启用后，辅助点和工件点会被调用进模板的放料点上方与放料点位置。

### 5.5 IO 定义（3.0 附表，端口号固定）

**输入**
| 端口 | 含义 |
|---|---|
| X02 | 冲床模式：接放料工位冲床，程序运行时须置 1，变化即报「冲床模式错误」 |
| X03 | 冲床模式 2：换向功能下接取料冲床，作用同 X02 |
| X05 | 主吸盘真空（主吸盘与工件间负压时置 1） |
| X06 | 副吸盘真空（接副吸盘，一般用于吸取要丢弃的余料） |
| X11 | 取料上死点（接取料工位冲床），不置 1 时本站不去取料工位 |
| X12 | 放料上死点（接放料工位冲床），不置 1 时本站不去放料工位 |
| X13 | 允许取料（接上一台 Y12），0→1 时本站去取料工位 |
| X14 | 允许放料（接下一台 Y11），0→1 时本站去放料工位 |
| X16 | 紧急急停（可接示教器急停，置 1 报紧急停止，**置 0 后才能清报错**） |

**输出**
| 端口 | 含义 |
|---|---|
| Y05 / Y06 | 主吸料 / 副吸料（置 1 吸气，置 0 停止） |
| Y11 / Y12 | 取料完成（接上一台 X14）/ 放料完成（接下一台 X13） |
| Y14 / Y15 | 冲床启动（放料工位冲床）/ 冲床启动 2（换向时接取料冲床） |

- **放料完成逻辑两种**：放料工位是冲床 → 放料并冲压结束后输出；放料工位是中转台 → 放料结束回到「放料待机点-回」后输出。

**接线注意事项**：各台控制器/外接 IO 板必须共用同一 24V 电源**或共地**；接完逐个打开输出，检查对应输入是否置 1；出现「开一个输出导致两个输入同时置 1」多半是两个输入端子铜丝外露并在一起。

### 5.6 运行逻辑（3.0）
- 机器人**手上无料**：取料工位有料 → 直接去取料，不做信号判断；取料工位无料 → 判断前站允许取料信号再去取。
- 机器人**手上有料**（先放后取再放）：放料工位无料 → 在放料待机点等允许放料信号；放料工位**有料未冲** → 本站发冲床启动信号让冲床冲压一次，同时在放料待机点等允许放料信号；放料工位**有料已冲** → 等允许放料信号后放料，下工位机器人手上无料会直接去取。
- **启动示例（搬运，取料工位=冲床，放料工位=中转台）**：无料时取料工位有料已冲 → 判断冲床是否在上死点再去取；无料 → 等允许取料信号。手上有料时放料工位无料 → 直接去放；放料工位有料 → 等下工位发取料完成信号后再放。

### 5.7 冲压指令各点信号逻辑（3.0 附表）
| 点位 | 输出 | 输入 | 联机逻辑 |
|---|---|---|---|
| 1 取料待机点 | — | — | 搬运/下料：上工位允许取料 X13=0-1、取料机床上死点 X11=1-0-1；上料机：下工位允许取料 X13（信号类型由工艺参数设） |
| 2 取料上方点 | 主吹气 Y07=1、副吹气 Y08=1 | 输出取料中 Y09=1 | — |
| 3 取料点 | 双治具开 Y05=1 & Y06=1；单治具 Y05=1 | — | 真空检测开始：主吸盘真空 X03=1 在通断检测时间内建立真空；副吸盘真空 X04=1 同理 |
| 5 取料待机点-回 | 取料中 Y09=0、取料完成 Y11=1 | — | — |
| 6 放料待机点 | — | — | 搬运/上料：下工位允许放料 X14=0-1、放料机床上死点 X12=1-0-1；下料机：下工位允许取料 X14（信号类型由工艺参数设） |
| 7 放料上方点 | 开启治具辅助、主吹气 Y07=1、副吹气 Y08=1 | 放料中 Y10=1 | — |
| 8 放料点 | 双治具 Y05=0；单治具 Y05=0 | — | 主吸盘真空 X05=0 在通断检测时间内破空完成；副吸盘真空 X06=0 同理 |
| 10 放料待机点-回 | 冲床启动 Y14=1、放料中 Y10=0 | — | — |

## 6. 报警 → 参数对应（FAQ + 3.0 附件1/2）

| 报警 | 原因 / 处理 |
|---|---|
| 冲床模式错误 | 冲床模式 X02 未置 1，或冲床处于急停状态 |
| 冲床执行周期小于冲压最短周期 | 冲压时间 < 冲压最短周期 → 工艺参数里**增加冲压最短周期时间**；或冲床上死点信号受干扰 |
| 冲床未回到上死点，冲压时间超过最长周期 | 冲压时间 > 冲压最长周期 → 放宽最长周期 |
| 冲床信号异常，未执行冲压过程 | 输出冲床启动信号后上死点时间无变化，或冲床未启动 |
| 冲床安全信号异常 | 启用该功能后启动冲床时 X07 未置 1（检查 X07 或干扰） |
| 取料/放料冲床未在上死点 | 启动冲床时冲床未在上死点，或上死点信号未接 |
| 放料待机点与放料上方点间距过小（取料同理） | Y 向距离 < 冲压参数里的「点位最小间隔」→ 减小该参数或加大上方点与取/放料点的距离 |
| 允许放料/允许取料信号异常 | 信号在过程中变化 → 排查干扰、接线；各台机器人地线串起来 |
| 主/副治具真空检测超时 | 取料失败，或取完料去放料过程中掉料 |
| 破空检测失败 | 程序过了放料点工件还在吸盘上，或主吸盘真空信号未置 0 |
| 检测到放料冲床上死点异常掉落 | 冲压完后人工再次冲压，或冲床从上死点异常掉落 |
| 提示启动错误机器人不在安全位置 | 工作模式为上料机/搬运/下料机时，机器人当前位置不在取料待机点到放料待机点之间；单机模式则必须在取料待机点 |
| 真空检测失败（3.0） | 取料点未构成真空 → 运行到取料待机点-回 |

**异常处理（3.0 附件2）**
1. 提前放料 → 去掉放料点上方指令的**平滑**；看是否启动了吹气功能。
2. 放料点和取料点停留时间相同 → **真空检测开关未打开**。
3. 只在放料点停留 → 检查冲压参数里的「放料时间」是否设了数值。
4. 运行中有停顿 → 平滑未拉满；或位于取料/放料待机点处信号未满足。
5. 频繁报真空检测超时 → A 主吸料输出与主吸盘真空输入是否过继电器；B 电柜是否加了风扇；C 料是否真没吸出来或掉料；D 吸盘是否损坏。
6. 频繁报允许取料/允许放料信号异常 → 各台机器人地线串起来；检查线路是否接错。

## 7. 参数设置推荐顺序（现场调试逻辑）

1. 工作模式（单机/上料/搬运/下料）+ 本站类型（放料台/冲床/翻转台/空中接力）→ 前后站信号与联机通信。
2. 冲床参数：允许控制冲压 → 冲床编号与最大冲床数 → 上死点 → 冲压时长/动作时长 → 冲压超时与反应超时 → 冲压成功确认时间 → 模内检测。
3. 治具：类型 → 真空检测 → 通断延时报警；再配治具 IO（主副吸料、吹气、治具状态）。
4. 干涉区；如需要再配码垛。
5. 速度：首模速度比/首模运行速度 → 模内逃跑速度比 → 各档位全局速度。
