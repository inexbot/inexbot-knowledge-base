## 2. ⭐ 本轮新观察：上游「路由形态」再次放宽（非破坏性）

11-19 实测上游切到「`.html` 后缀路由」（裸路径一律 404），据此给 index 加了
`url_suffix` 字段并让 proxy 输出带后缀的链接。**本轮实测两种形态同时可用**：

| 请求形态 | 实测结果 |
|---|---|
| 裸路径 `/zh/…` | **200** |
| 裸路径 + `.html` | **200** |
| 目录页裸路径 `/zh/…/` | **200** |
| 目录页 + `/index.html` | **200** |
| 姊妹 KB `open.inexbot.com` 裸路径 | **200**（未受影响，与 11-19 一致） |

抽样 30 条真实 index 条目：**裸形态 30/30 200，带后缀形态 30/30 200**。

⇒ **判定：非破坏性放宽**（上游同时保留了两套路由）。
⇒ **不需要改代码**：proxy 当前输出的仍是**带后缀形态**，实测 `74/74 全 200`，
   用户点得到链接。
⇒ ⚠️ **但这是「双形态并存」状态，不是「回到裸形态」** ——
   裸形态虽然现在可用，但**不要**据此把 `url_suffix` 字段删掉或让 proxy 改回裸形态：
   一旦上游再次收紧成「只认后缀」，删掉就又是一次 100% 404 故障（正是 11-19 那轮）。
⇒ **保留 `url_suffix` 字段 + 保留后缀输出** 是当前最稳的形态（两种路由下都可达）。
